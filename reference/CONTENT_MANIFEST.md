## Структурные преобразования

| Исходная форма                           | Типизированная форма                                   | Причина                                                                    |
| ---------------------------------------- | ------------------------------------------------------ | -------------------------------------------------------------------------- |
| `79 PLN`, `100 PLN` и другие цены-строки | Числовое поле + `currency: "PLN"` + optional prefix    | Арифметическая и типовая корректность без изменения отображаемого значения |
| `от 1 000 PLN`                           | `price: 1000`, `pricePrefix: "от"`, `crossedOut: true` | Сохранение семантики цены и перечёркивания                                 |
| `<em>повышает чек мастера</em>`          | `before` + `emphasis`                                  | Будущее безопасное JSX-отображение без HTML-строк                          |
| `src="data:image/png;base64,..."`        | `imageId`                                              | Изображения уже сохранены и зафиксированы на этапе 3                       |
| HTML-списки                              | Readonly arrays                                        | Строгая структура без HTML-строк                                           |
| `data-plan="guide"`                      | `planId: "guide"`                                      | Стабильная типизированная связь CTA с тарифом                              |
| JavaScript template literal сообщения    | Pure function + typed template                         | Повторяемость без browser API и URL-сборки                                 |
| Legal HTML strings                       | Discriminated union typed blocks                       | Отказ от `dangerouslySetInnerHTML`                                         |
